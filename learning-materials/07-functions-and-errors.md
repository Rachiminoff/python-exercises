# 7 — Functions & Error Handling

Covers: defining functions, parameters/default args, `*args`, `try`/`except`/`else`/`finally`, raising exceptions.

## Resources

- **[Official Tutorial — Defining Functions](https://docs.python.org/3/tutorial/controlflow.html#defining-functions)** — Covers default arguments, *args, and **kwargs directly from the source.
- **[Official Tutorial — Errors and Exceptions](https://docs.python.org/3/tutorial/errors.html)** — The canonical guide to try/except/else/finally and raising your own exceptions.
- **[Official Docs — Built-in Exceptions](https://docs.python.org/3/library/exceptions.html)** — Look up exactly which exception (ValueError, ZeroDivisionError, etc.) you're catching.
- **[Real Python — Python Exceptions: An Introduction](https://realpython.com/python-exceptions/)** — Friendlier walkthrough of exception handling with practical examples.
