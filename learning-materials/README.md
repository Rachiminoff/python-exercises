## General references worth bookmarking

- **[Python Official Docs — Tutorial](https://docs.python.org/3/tutorial/index.html)** — the primary source of truth; dense but always correct.
- **[Python Official Docs — Standard Library](https://docs.python.org/3/library/index.html)** — look up any built-in function or module here.
- **[Real Python](https://realpython.com/)** — long-form tutorials that explain *why*, not just syntax; great when a docs page feels too dry.
- **[W3Schools Python](https://www.w3schools.com/python/)** — fast syntax lookups with a runnable example for almost everything.
- **[Python Tutor](https://pythontutor.com/)** — paste in your code and step through it line by line, watching variables change. Excellent for "why isn't this working."
