# 💡 Hints — Valid Parentheses

*Tags: string, stack*

Try the problem for real first. These are ordered from vague to specific — stop reading as soon as you

## Hints

1. This is a classic stack problem — use a Python list as a stack with .append() and .pop().
2. Push opening brackets onto the stack. When you hit a closing bracket, it must match the top of the stack.
3. If the stack still has items left at the end, something was never closed.

## Relevant functions & syntax

`list.append()`, `list.pop()`, `dict (bracket-pair lookup)`
