# 🧩 Mini LeetCode (Easy DSA)

A dozen classic easy-tier data-structures-and-algorithms problems, the kind you'd see in a technical screen.
Each one is self-contained: read the docstring, implement the function, then run the file directly — it checks
itself against the sample tests at the bottom and prints "All sample tests passed!" when you've got it.

## Rules

- 🚫 **No AI.** No ChatGPT, no Copilot, no autocomplete you didn't type yourself.
- ✅ **Google is fine** for syntax, docs, and built-in functions — just not the solution itself.
